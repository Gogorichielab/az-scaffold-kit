# Azure Free Tier Services Cheat Sheet

Common Azure services with free-tier options (availability and limits vary by region/account type):

- Azure App Service (limited free/shared hosting options)
- Azure Functions (monthly free execution grant)
- Azure Static Web Apps (free tier)
- Azure Blob Storage (limited free capacity/transactions in trial or free account terms)
- Azure Cosmos DB (free tier request units and storage option)
- Azure SQL Database (limited free offers/trial credits)
- Azure Container Registry (limited free/basic trial availability)
- Azure Kubernetes Service (control plane is free; pay for worker node compute)
- Azure Key Vault (limited operations may be covered by free credits)
- Azure Monitor / Log Analytics (limited free data ingestion/retention)

> Verify current limits on Microsoft’s official pricing pages before provisioning.
