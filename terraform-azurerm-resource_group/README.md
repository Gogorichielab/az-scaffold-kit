# terraform-azurerm-resource_group

Terraform module scaffold for provisioning an Azure Resource Group.

## Files
- `main.tf`: Core resource, variables, and outputs
- `.github/workflows/ci-terraform.yaml`: Terraform CI workflow
- `ExampleConfiguration/main.tf`: Example module usage
- `checkov-security-scan/results_cli.txt`: Security scan output placeholder

## Usage
Use the example in `ExampleConfiguration/main.tf` as a starting point.
